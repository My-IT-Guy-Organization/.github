# Decision Records

Short records of significant technical or process decisions — an
[ADR](https://adr.github.io/)-lite log so future-us knows *why*, not just *what*.

## How to add one

1. Copy the format of an existing record.
2. Name the file `NNNN-short-title.md` (next number, kebab-case title).
3. Keep it short: context, the decision, and the consequences.
4. Don't edit old records to change history — if a decision is reversed, add a
   new record that supersedes it and link back.
